# Full HD 송출과 내 화면 미리보기

**화면 공유 시작**에서 브라우저의 실습실 탭 또는 창을 고른다. 캡처는 1920×1080을 우선 요청하고 최대 1920×1080·15fps로 제한한다. 기존 송신 상한 2.5Mbps와 해상도 우선 정책을 유지한다. 모든 원본을 강제로 Full HD로 늘리지 않으며, 창의 크기·비율·브라우저·네트워크에 따라 실제 캡처와 인코딩 크기는 달라질 수 있다.

4K 전체 모니터를 Full HD로 줄이면 글자도 작아진다. 필요한 실습실 탭·창만 고르고 편집기 글자를 조절하면 읽기 좋다. 현재 진행 화면을 캡처하면 미리보기가 반복될 수 있어 지원 브라우저에 현재 탭 제외를 요청한다. 최종 공유 대상 선택은 브라우저에서 사용자가 직접 한다.

공유를 시작하면 중앙에 **내 송출 화면**이 크게 표시된다.

- **작게 보기**: 편집 화면 옆의 작은 미리보기로 돌아온다. 작성한 초안은 유지한다.
- **크게 보기 / 내 송출 화면**: 중앙 공간을 미리보기로 쓴다. 참여자 목록과 아래 단계 안내는 유지한다.
- **전체 화면**: 브라우저 전체 화면으로 같은 영상을 본다. Escape 또는 전체 화면 나가기로 돌아온다.
- **도와주기 / 전체 화면 모아보기**: 참여자 보기가 중앙을 사용하도록 내 미리보기는 비켜난다. 송출은 계속된다.

내 미리보기는 캡처 중인 같은 MediaStream을 로컬에서 재생한다. 크기 전환 때 새 캡처·SFU 시청 연결·재송출을 추가하지 않는다. 참여자의 실제 수신 화면을 다시 받아 검증하는 기능은 아니다.

**캡처** 크기는 track.getSettings, **송출** 크기는 outbound-rtp 통계의 frameWidth/frameHeight로 확인하며 보이는 탭에서 약 3초마다 갱신한다. 아직 송신 통계가 없으면 크기 확인 중으로 표시한다. 이 표시가 참여자 전원의 해상도·지연을 보장하지는 않는다. 공유 중지·브라우저 중지·로그아웃은 기존 송신을 중단하고 미리보기에서도 스트림을 해제한다. 캡처 선택 중 로그아웃하면 늦게 도착한 캡처도 즉시 중단한다.

상단에는 **설정** 버튼만 둔다. **새 모임**은 설정 안으로 옮겼다. 생성 결과 복구 안내와 기존 `#prepare` 링크는 계속 사용할 수 있다. 설정의 요청 기록·알림, 관리 진입과 기존 인증 정책도 유지한다.

## 검증

`test/lab-broadcast-preview.mjs`의 실제 페이지·합성 캡처/RTC 16개 검사는 Full HD 요청과 측정 표시, 3840×2000·1920×980·390×844 배치, 같은 스트림 재사용, 크게/작게/전체 화면, 참여자 지원 우선, 초안 유지, 중지·로그아웃 정리를 확인한다. Aside에서도 로컬 합성 화면을 확인한다. 실제 참여자에게 새 화면 공유를 켜거나 실제 공급자 자원을 생성하지 않는다. 실제 망의 화질·지연 측정은 별도다.
