# 모임지기 수업 진행 화면

주 사용 환경은 1920×1080, 브라우저 확대 100%다. 브라우저 상단을 감안한 1920×980에서도 기본 수업 운영을 페이지 스크롤 없이 수행한다. 기존 화면의 색상·인증·수업 API를 유지하면서 배치와 지원 전환을 바꾼다.

## 수업 중 사용하는 자리

- 상단: 선택한 모임, 남은 시간, 데이터 최신성, 인증 상태. 수업 메뉴와 명령 전달 일시정지, 자료·코드, 모임 도구를 바로 연다.
- 중앙: 내 시연실의 실제 파일 편집기와 명령 입력, 또는 선택한 참여자의 실습실 화면. **전체 화면 모아보기**로 중앙을 전체 미리보기로 쓸 수도 있다.
- 오른쪽: 도움 요청과 참여자 미리보기. 참여자의 본인 진행 표시·제출 수를 영상과 함께 표시한다. 영상 연결·활동 여부를 학습 이해도나 완료로 판단하지 않는다.
- 하단: 현재 단계, 모임지기 안내, 예시 문장, 다음 단계 버튼. 개별 지원 중에도 계속 보인다.

**도와주기**를 누르면 중앙에서 그 사람 화면과 지원 도구를 연다. 클릭·키보드는 기존의 별도 제어 요청과 참여자 허용 후에만 보낸다. **내 시연·진행으로 돌아가기** 또는 중앙의 **작게 보기**는 제어 종료를 요청하고 내 작업으로 돌아온다. 종료 확인이 안 된 제어는 기존 차단 정책과 종료 재확인 버튼을 유지한다. 지원을 열었다고 손을 내리거나 해결로 표시하지 않는다.

중앙으로 옮길 때 기존 video 요소와 RTCPeerConnection을 사용한다. 시연 초안과 영상 연결을 새로 만들지 않는다. 시연 명령은 시연실 전용이고 **함께 실행**은 확인 후 선택한 참여자 자리에서 실행한다.

**자료·코드**는 기존 코드 전달 도구를 펼친다. 자료 파일은 수업 준비와 참여자의 자료 넣기 흐름을 사용한다. **모임 도구**는 초대·자원·복구·마무리 도구를 같은 화면의 대화상자로 연다. Escape 또는 닫기로 수업에 돌아오며 작성 중인 입력은 유지한다. 초대 QR을 크게 열면 도구 패널을 닫아 QR이 뒤에 가려지지 않게 한다.

상단은 **설정** 버튼만 남기고 **새 모임**은 그 안으로 옮겼다. 설정은 최대 520px 폭이며 긴 안내는 접어 둔다. 수업 중 **좌석 추가**로 현재 조건의 한 자리를 만들고 새 좌석만 초대할 수 있다. [사용법과 응답 유실 복구](classroom-seat-add.md).

개설 요청은 **참여자 자동 미리보기** 위쪽의 회색 대기 자리에서 바로 승인한다. 별도의 상단 요청 메뉴는 제거하고, 지난 기록·기기 알림은 설정의 작은 링크로 연다. [승인 조건·같은 요청 복구·본인 로그인 안내](classroom-request-previews.md).

**내 송출 화면**은 중앙에서 크게·작게·전체 화면으로 본다. Full HD를 우선 요청하고 실제 캡처·송출 크기를 표시한다. [해상도와 미리보기 사용법](classroom-broadcast-preview.md).

## 크기와 예외

- 1920×1080·1920×980, 참여자 5명에서 기본 시연 작업, 도움 요청, 참여자 목록, 안내가 화면 안에 보이는 것을 검사한다.
- 참여자가 많거나 설명·오류가 길면 해당 영역 안에서 스크롤한다. 수업 준비·피드백 같은 긴 양식과 도구 패널도 자체 스크롤을 사용한다. 모든 길이의 콘텐츠가 동시에 펼쳐진다는 의미는 아니다.
- 작은 창과 확대 화면에서는 내용이 잘리지 않게 세로 배치로 전환한다. 휴대폰에서는 도움 요청을 진행 내용보다 먼저 놓고 도구를 버튼으로 연다.
- 화면 지원이 없으면 별도 참여자 진행 목록과 기존 상태표를 사용할 수 있다. 상태표 지원은 도구 패널에서 연다. 읽기 전용·관리 만료·로그아웃·새로고침 인증 복원은 기존 정책을 따른다.

## 검증 범위

`test/lab-command-center.mjs`에서 실제 페이지 모듈과 합성 RTC·보안 키·서버 응답으로 배치와 지원 전환을 확인한다. Aside는 현재 실행 화면 확인에 사용하며, Aside에 없는 뷰포트 변경과 합성 RTC 검사에는 격리 Edge를 사용한다. 실제 참여자 PC나 공급자 자원을 조작하지 않는다. 스크린샷과 결과는 `.artifacts/classroom-command-center-20261016`에 보관한다.

1920 화면, 브라우저 상단을 감안한 높이, 1366 노트북, 확대 상당 980 폭, 휴대폰 390 폭을 포함한다. 12명 목록에서 패널 내부 스크롤, 이동된 영상의 재생 유지, 동의 전 입력 차단, 동의 후 정확한 자리 입력, 복귀 시 제어 종료, 시연 초안·도구 초안·포커스 유지, 안내 단계 저장을 검사한다. 기존 운영 UX·관리/모니터·로그아웃 경합·인증 복원·수업 화면 검사도 함께 실행한다. 합성 RTC 검사는 실제 Daytona·SFU 영상 지연이나 화질의 재측정을 대신하지 않는다.

2026-10-16 검증 결과: 새 화면39·운영40·관리/모니터98·인증 복원9·로그아웃 경합25 및 수업·영상 지원·화질 검사가 통과했다. 16:48 KST에 v2026.10.16.15의 공개 HTML과 소스 해시 일치 및 기존 인증 경계 응답을 확인했다.
