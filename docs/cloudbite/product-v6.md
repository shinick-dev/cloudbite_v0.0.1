# Constructive project advice

Cloudbite helps a person develop an ambiguous project into a defensible next decision. An expert's concern should
lead to a specific proposed change, a proportionate check, and the observation that would change its recommendation.
Missing information is distinguished from adverse evidence, tradeoffs and a stated constraint. Material risks remain
visible; a positive verdict is not required and unsupported claims are not made more acceptable.

## User workflow

1. Enter the project in the normal brief. An optional local drafting helper asks up to three questions; direct entry
   and execution remain available. Review and explicitly apply its draft before any of it enters the brief.
2. Run the selected expert team. Reports describe the strongest feasible scoped approach and concrete remedies for
   the material concerns they identify. Ordinary opinion fields and original results remain unchanged.
3. On a finished live project, request the optional memo. In the same single memo call it proposes a viable path,
   up to three prioritized repairs, a revised objective/scope/next milestone and decision-changing questions.
   A rough brief without comparison options is eligible. The system does not invent user-adopted option IDs.
4. Read and edit proposals before using them in a follow-up. Nothing silently changes the parent brief, records a
   generated claim as the user's known fact, or starts a new sandbox or model call.

The source-support checks, original opinions, optional peer review, author-response workflow, history controls,
authentication and project budgets retain their existing authority. A new memo still has one paid attempt per
project. A failed attempt is visible and is not automatically retried. Old stored memos remain readable as stored.

## Limits

The input helper is a local drafting aid, not a Jev or Nosana call. Structured coaching is generated advice, not a
verified business plan, a calibrated success estimate or a set of requirements agreed by the user. Exact schema,
reference, language and byte bounds can be checked by software; practical usefulness and the validity of the advice
still need evaluation on real projects. The memo discloses that it does not read full expert reports or source pages.

## Start

Run `npm run dev` and open `http://localhost:8808/cloudbite?lang=ko` (or `lang=en`). Live expert execution requires the
existing server-side Daytona and Nosana configuration and an authorized owner or visitor session. The local tests use
synthetic provider replies and must not be presented as observed model or customer outcomes.
