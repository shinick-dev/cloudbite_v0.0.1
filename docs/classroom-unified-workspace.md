# 내 시연과 참여자 지원

## 기본 사용

1. 모임을 고르고 **시연실 만들기**를 누른다. 준비가 끝나면 전용 VS Code를 중앙에 자동으로 연다. 파일·OpenCode·터미널을 그 안에서 직접 조작한다. 추가 자원·요금 확인은 유지하며, 이미 만든 시연실은 상태만 확인해 다시 연다.
2. **시연 송출 시작**을 누른다. 화면 선택창 없이 내 시연 영역만 영상으로 전송한다. 중앙에는 영상을 재생하는 대신 실제 편집 화면이 유지된다.
3. **참여자 모아보기**로 중앙 화면을 바꾼다. 같은 버튼이 **내 시연 보기**로 바뀌며 다시 누르면 돌아온다. 시연 초안과 송출은 유지된다.
4. 새 도움 요청이 오면 해당 참여자가 중앙에 자동 표시된다. 헤더의 **입장 아이디 · 좌석번호 · 도움 요청**으로 대상을 확인한다. 참여자 영상이 없으면 연결 대기를 표시한다.
5. **도움 마치기**로 현재 지원을 마친다. 대기 요청이 있으면 다음 사람으로 넘어가고, 없으면 직전 시연 또는 모아보기로 돌아온다. 기존 제어의 종료가 미확정이면 다른 사람 제어를 시작하지 않는다.

## 송출 범위

송출 원본은 모임지기의 시연 영역이다. 참여자 지원이나 모아보기로 바꾸어도 전체 모임에는 시연 원본이 유지된다. 관리 화면·도움 요청 목록·다른 참여자 영상은 기본 송출에 포함하지 않는다.

시연 화면은 실제 DOM을 영상으로 만든다. 출력 캔버스는 1920×1080이며 글자·명령 결과가 변경되면 갱신한다. 캔버스 트랙과 기존 SFU 송신은 최대 15fps·2.5Mbps 정책을 사용하지만 실제 화면 갱신 속도는 렌더링 시간에 따라 달라진다. 참여자의 수신 해상도·지연을 보장하는 수치는 아니다. 새 SFU 시청 연결을 추가하지 않는다.

중앙의 전용 VS Code는 논리 해상도 1920×1080으로 열고, 모임지기 화면에서는 남는 공간에 맞춰 축소한다. **시연 크게 보기**, **전체 화면**으로 표시 크기를 바꿔도 송출 해상도는 유지한다. **새 탭으로 열기**는 선택 기능이다. 중앙 연결이 안 되면 **다시 연결**로 새 입장 정보를 받는다. 재연결은 이전 송출을 멈추므로 화면이 열린 뒤 **시연 송출 시작**을 다시 누른다. 별도 프로그램을 보여주려면 **다른 화면 → 다른 탭·창 공유**를 선택하고 브라우저에서 공유 대상을 직접 고른다. 외부 화면 공유는 선택한 대상이 그대로 전송되므로, 관리 탭 대신 보여줄 실습실 탭·창을 고른다.

지원 중에는 보이지 않는 시연 원본을 유지한다. 모임 전환·로그아웃·시연 원본 소실 시에는 이전 시연 송출을 정리한다. 교안 편집·제출·복습 화면으로 이동하면 시연 송출을 멈추므로 수업 진행 화면에서 다시 시작한다. 페이지 새로고침과 탭 종료도 송출을 끝낸다.

## 자동 지원과 제어

처음 읽은 기존 손들기는 기준 상태로 기억하고, 그 뒤 새 요청만 자동으로 연다. 같은 요청을 반복 조회하거나 새로고침했다고 화면을 계속 빼앗지 않는다. 현재 선택한 모임만 대상으로 하며, 이미 돕는 사람이 있으면 추가 요청은 대기한다. 이미 열린 지원을 새 요청이 강제로 덮어쓰지 않는다.

자동 확대는 관찰이다. 클릭·키보드 입력은 기존 **제어 요청 → 참여자 허용** 후에만 가능하다. 자동 전환은 참여자 입력으로 포커스를 옮기지 않는다. 도움을 마쳤다고 참여자의 학습 완료·결과물 보관 확인을 대신 표시하지 않는다. 입장 아이디는 참여자가 입력한 표시 이름이며 외부 서비스의 검증된 계정 ID를 뜻하지 않는다.

## 개발 검증

새 캡처 빌드: `npm run build:lab-demo-broadcast`. `npm run check`와 Wrangler 빌드는 생성물이 원본과 일치하는지 확인한다. 캡처 수명·범위·텍스트 갱신은 `test/lab-demo-broadcast.mjs`, 자동 지원 대기는 `test/lab-live-auto-help.mjs`, 통합 전환과 실제 캔버스 트랙은 `test/lab-unified-workspace.mjs`에서 검증한다. 합성 API·RTC는 실제 공급자 자원이나 실제 참여자 제어를 실행하지 않는다.

v2026.10.16.19 검증: 통합25·기존 진행39·외부 공유16, 자동 지원/종료 경합·수업 구성 UI·기존 영상 지원·화질 검사가 통과했다. 캡처 원본 소실, 비동기 렌더링 중 모임/권한 전환, 외부 track.stop, 화면 밖 시연 유지 5개 독립 검사도 통과했다. TypeScript·생성물 일치·Worker dry-run과 정적 detector(0건)를 확인했다. 정적 검사와 제한된 화면 확인은 전체 접근성 인증이 아니다.

Aside에서도 중앙 모아보기 전환과 자동 지원 헤더, 시연 원본 유지 및 화면 선택창 미사용을 확인했다. 운영 HTML은 코드 `1566244`와 SHA-256이 일치하고 기존 인증 없는 요청401·Origin 없는 요청403을 확인했다. 실제 수업망에서 참여자의 수신 지연·화질을 재측정한 검사는 아니다. 설치 웹앱은 새로고침하면 새 화면을 받는다.

## 중앙 VS Code 연결 보완

시연실은 동일한 iframe을 유지한다. 참여자 모아보기·도움 요청·함께 실행으로 전환할 때 프레임을 다른 DOM 부모로 옮기거나 다시 만들지 않는다. 표시에서 숨길 때만 화면 밖에 보관하므로 편집 상태와 기존 송출이 유지된다. 시연실이 중앙에 있을 때도 수업 방식 버튼은 위쪽에 남는다. 새로고침은 기존 시연실을 재연결하며 새 샌드박스를 만들지 않는다.

실습실 삽입은 인증된 비공개 시연 자리에서만 허용한다. 루트 iframe 탐색과 영상 다리 스크립트는 캐시를 우회해 자리·부모 모임을 확인한다. 다른 참여자 자리의 프레임 정책은 유지한다. 다리는 정확한 부모 출처, iframe 창, 송출별 난수와 프레임 순서를 확인해 픽셀만 전달한다. 관리자 토큰·DOM·원격 입력 명령은 보내지 않는다. 첫 유효 프레임이 오기 전에는 스트림을 만들지 않으며, 원본이 오래되거나 권한·모임이 바뀌면 송출을 정리한다.

검사: `test/lab-demo-embed-host.mjs`(11개 묶음), `test/lab-demo-workspace.mjs`, `test/lab-demo-embed-bridge.mjs`, `test/lab-embedded-demo-ui.mjs`(18개)와 기존 실습실 보안289·진행39·통합25·외부 공유16 검사를 통과했다. 새 통합 검사는 실제 DOM 캡처 번들·브라우저 iframe·ImageBitmap·MediaStream을 사용하지만 실습실 화면과 SFU/API는 합성이다. 실제 Daytona의 전체 VS Code 초기화·OpenCode와 참여자 PC의 영상 수신은 별도 실물 확인 대상이다.

### 중앙 화면 연결 거부 수정

새 탭에서는 열리는데 중앙 iframe만 거부되는 캐시 재검증 경로를 수정했다. code-server가 `304`와 `frame-ancestors self` 또는 `X-Frame-Options: SAMEORIGIN`을 돌려주면 기존 HTML 삽입 처리를 건너뛰었다. 인증된 비공개 시연실 iframe 탐색에서는 조건부 요청 헤더를 제거해 완전한 HTML을 받고, 응답을 no-store로 돌려주며 ETag/Last-Modified를 제거한다. 일반 참여자·자산·새 탭 경로의 캐시 정책은 유지한다.

`test/lab-demo-embed-browser.mjs`는 실제 workerd/SQLite State/Edge를 사용한다. upstream code-server만 합성이다. 일반 입장, 캐시된 문서, 폴더 리다이렉트, 리다이렉트 뒤 캐시 재검증, 캐시 준비 뒤 시연 역할 제거 시403을 확인한다. 수정 전 실제 브라우저의 frame-ancestors self 차단을 재현했고 수정 후 통과했다.

### 중앙 송출 버튼 표시 보완 (v2026.10.16.22)

송출 제어는 참여자 화면 세션과 별도로 현재 모임을 기준으로 표시한다. 참여자 화면 세션이 만료되어도 유효한 관리자 인증이 있으면 기존 관리 송출 API로 시작할 수 있다. 두 권한이 모두 없으면 버튼을 비활성화하고 보안 키 재확인을 안내한다. 서버의 인증·권한 검사는 유지한다.

시연실이 중앙에 열려 있으면 제목줄에 **시연 송출 시작**을 표시한다. 전체 화면에서도 같은 버튼을 사용하고, 참여자 모아보기·지원 중에는 상단으로 옮겨 중지할 수 있다. 송출 전에는 **나만 보는 중**, 시작 후에는 송출 상태를 표시한다. 시연실 만들기나 새로고침만으로 자동 송출하지 않는다.

검증: 송출 권한/표시4·중앙 시연실20·외부 공유16·진행39·통합25·수업 구성 UI·타입/생성물·dry-run 통과. Aside에서도 화면 세션이 실패한 합성 중앙 시연실에 버튼이 남는 것을 확인했다. `tools/lab-demo-broadcast-smoke.mjs`는 명시적 RUN_REAL_SFU=1과 환경 변수 토큰으로만 실행하는 유료 서비스 통합 검사다. 합성 모임·인증·편집 화면과 실제 Cloudflare SFU/송수신 스크립트/WebRTC를 연결해 참여자 영상1920×1080, 편집 픽셀 변경 수신, 전체 화면 제어, 송출 중지 전달을 확인했다. 실제 Daytona나 운영 모임을 만들거나 바꾸지 않았으며 실제 참여자 PC·망의 품질 보장은 아니다. 검사 증거는 `.artifacts/classroom-broadcast-controls-20261016/real-sfu.json`에 저장한다.
