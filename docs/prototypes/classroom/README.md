# 공부방 수업 흐름 목업

2026-10-16 사용자가 Aside에서 체험한 뒤 이 구성을 구현 기준으로 승인했다.

`index.html`은 외부 리소스·빌드 도구 없이 열리는 독립 HTML이다. 브라우저에서 파일을 직접 열거나 이 폴더를 정적 서버로 제공한다. 현재 PC의 체험 주소는 `http://127.0.0.1:8894/`다. 다른 기기에서는 접근할 수 없는 로컬 주소다.

## 체험 순서

1. 모임지기 화면에서 **예시 초안 만들기**, **메모 대조하기**를 누른다.
2. **함께 실행**에서 참여자를 골라 한 줄을 보내고 대상 확인을 체험한다. 내 시연실과 참여자 각자의 실행이 분리돼 있다.
3. 도움 대기의 **준호 → 도와주기 → 제어 요청 → 참여자 화면에서 확인**을 누른다.
4. 참여자 화면에서 제어를 허용하거나 거절한다. 제어 허용은 5분이며 어느 쪽에서도 끝낼 수 있다.
5. 참여자의 결과.txt를 편집하고 **제출**한다. 모임지기 **제출·피드백**에서 의견을 남기면 참여자 화면에 연결된다.
6. **복습하기**에서 시각을 선택하고 해당 단계부터 이어서 연습한다.

텍스트 파일을 골라 브라우저 안에서 열 수 있고, 결과.txt를 실제로 내려받을 수 있다. 내려받기와 참여자가 직접 열어 확인하는 기록은 구분한다.

## 범위

- 참여자·시간·제출물·실행 응답은 가상 예시다. 실제 AI, Daytona, 실습실 API, 보안 키, 녹화·음성 서버에 연결하지 않는다.
- 시연실에서 입력한 명령은 모임지기 예시 상태만 바꾼다. 함께 실행은 고른 참여자 각각의 예시 상태에만 반영한다. 임의 명령을 PC나 서버에서 실행하지 않는다.
- 사용자가 고른 파일은 이 탭의 메모리에서만 읽는다. 업로드 서버와 브라우저 저장소에 자동 저장하지 않는다. 새로고침이나 초기화 시 체험 기록이 초기화된다.
- 역할 전환은 같은 브라우저 안에서 두 관점을 체험하는 장치다. 실제 인증·권한 구현의 대체물이 아니다.
- 네 플랫폼의 [UX 조사](../../research/teaching-platforms/2026-10-16.md)를 바탕으로 새로 작성한 목업이다. 포크한 LMS를 설치·통합한 실행판은 아니다.

## 원본과 생성

스타일 `style.css`, 참여자 화면 `learner.js`, 공통 상태·모임지기 흐름 `app.js`로 나뉜다. 변경 후 `node docs/prototypes/classroom/build.mjs`를 실행하면 세 파일이 `index.html`에 포함된다.

StackBite에서 Grok CLI `grok-4.7-build-fast --reasoning-effort high`로 스타일과 참여자 화면을 병렬 제작하고, 조율자가 모임지기 흐름·공통 상태·통합을 맡았다. 외부 UI 라이브러리나 원본 LMS 코드를 이식하지 않았다.

## 확인 결과

독립된 Edge의 로컬 예시에서 26개 동작 확인 통과: 실행 범위 분리, 명령 전달 중지, 동의·거절·제어 종료, 도움 맥락, 실제 편집 내용 제출, 양쪽 피드백, 파일 열기·다운로드·직접 보관 확인, 복습 이어가기, 모달 Escape, 모바일 탐색·승인, 외부 요청0건, JS 오류0건.

Aside에서 실제 목업을 열어 확인했다. 뷰포트 크기 조절이 지원되지 않아 1366×768 노트북과 390×844 휴대폰 배치 검사는 격리된 Edge로 수행했다. 주요 흐름에서 페이지 가로 넘침이 없었다. 근거는 `C:\Users\user\source\.artifacts\classroom-mockup-20261016\qa`에 있다. 이는 목업 검증이며 운영 서비스의 기능·성능 검증이 아니다.

## 실제 구현 순서

1. 모임지기 전용 실습실과 `시연 보기 / 함께 실행 / 개별 실습`의 대상·권한·수명 정책.
2. 기존 영상과 실습실을 연결한 한 창 구성, 참여자 단계·현재 안내.
3. 단계가 연결된 도움 요청·조교 담당·기존 동의 기반 제어.
4. 실제 파일 업로드·제출 버전·피드백·보관 확인.
5. 저장된 자료·녹화 시각·이어하기·수업 템플릿.

구현 시 관리8시간, 본인 전용 요청함·승인 보안 키, 자동 실습실 미리보기와 별도 제어 동의 경계는 유지한다. 이 목업을 현재 운영 화면에 그대로 덮어써 실제 기능이 되는 것으로 처리하지 않는다.
