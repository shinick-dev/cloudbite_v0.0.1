# 승인된 목업 방향

승인일 2026-10-16. 기존 공부방의 밝은 바탕과 파란 강조색을 이어받는 Operate 화면이다. 모임지기는 수업의 현재 단계·독립 시연실·참여자 상태·도움 대기열을 함께 보고, 참여자는 안내와 자기 파일·터미널을 한 창에서 다룬다.

- 64px 상단에 제품 이름·체험용 표시·역할 전환을 둔다. 넓은 화면의 210px 왼쪽 영역은 수업 메뉴와 단계다.
- 수업 화면은 유동적인 작업 영역과 280px 지원/안내 영역이다. 자료·동의·제출 확인만 모달을 사용한다.
- 바탕 `#f7f7f5`, 표면 흰색, 본문 `#20242c`, 강조 `#315cf2`. 편집기는 `#18212f`와 밝은 텍스트를 사용한다. 시스템 한글 글꼴, 12px 모서리, 경계선과 일정한 SVG 선 아이콘을 사용한다.
- 좁은 화면은 접힌 메뉴와 세로 작업 흐름으로 전환한다. 중요한 작업을 가로로 밀어 찾게 하지 않는다.
- 시연·일괄 실행·개인 실습, 보기·제어 동의, 자기 완료·제출·PC 보관 확인을 서로 다른 상태로 표시한다.
- 표시하는 숫자와 참여자는 예시다. 실제 생성·실행·인증·녹화가 동작한다고 암시하지 않는다.
