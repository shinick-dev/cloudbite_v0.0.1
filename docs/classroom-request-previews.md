# 자동 미리보기에서 개설 요청 승인

별도의 상단 개설 요청 메뉴 대신 **참여자 화면 · 자동 미리보기** 위쪽에 회색 대기 자리를 표시한다. 요청자의 이름·목적·종류·승인 조건과 **승인하고 열기**가 함께 보인다. 대기 중에는 회색 배경만 2.8초 주기로 천천히 변하고, 동작 줄이기 설정에서는 정지한다. 대기 요청이 없으면 공간을 차지하지 않는다. 요청이 많으면 해당 목록 안에서만 스크롤한다.

모임 합류는 현재 선택한 모임을 기본 대상으로 삼는다. **승인 조건 변경**에서 다른 모임을 고르면 그 선택을 유지한다. 개인 복습은 기본 1 CPU·메모리 2 GiB·디스크 5 GiB와 서버의 첫 시간·AI 한도 선택지를 사용한다. 조건 변경에서 기존 사양 프리셋·직접 사양·시간·한도를 정할 수 있다. 합류 자리는 대상 모임의 조건과 종료 시각을 따른다. 승인 전에 표시된 조건과 추가 자원 비용을 확인한다.

**승인하고 열기**를 누르면 기존 요청 ID와 선택 조건에 묶인 보안 키 확인을 수행한다. 승인 뒤 참여자는 자신이 요청한 화면에서 입장 링크를 받는다. 생성 중이거나 응답이 끊기면 새 승인 대신 **같은 요청 결과 확인**을 제공한다. 같은 탭 새로고침에도 비밀이 아닌 요청 ID만 보관해 재승인을 막는다. 보안 키 확인 후 승인 응답을 모르는 상황은 실패로 단정하지 않는다.

표시되는 요청은 15초마다 조회하며 숨은 탭에서는 주기 조회를 멈춘다. 조회 실패 뒤에는 이전 정보로 승인하지 않는다. 본인 로그인 권한을 잃으면 이름과 목적을 지우고, **기록·알림**에서 본인 로그인 후 다시 확인하도록 안내한다. 이 링크는 수업을 보존하도록 새 탭을 연다. 설정의 **요청 기록·알림**에서도 기존 전체 요청함과 기기 알림 설정에 접근한다. 관리 화면 로그아웃·인증 세대 변경 뒤의 늦은 응답은 요청 정보를 복원하지 않는다.

Cloudflare Access 본인 전용 `/api/lab/open/manager/*`와 기존 보안 키 승인·복구 API를 그대로 사용한다. 관리 토큰을 요청함 권한으로 대신 보내거나 새 우회 API를 만들지 않는다. 이 변경은 서버 데이터·비밀값·바인딩·마이그레이션을 바꾸지 않는다.
