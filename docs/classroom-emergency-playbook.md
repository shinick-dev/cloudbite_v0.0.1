# 수업 비상 운영 절차

모임지기와 참여자가 같은 순서로 쓰는 짧은 절차다. 이미 전달된 입력은 되돌릴 수 없다. 열린 연결과 호스트 캐시는 약 30초 남을 수 있다. 확인 표시, 일시정지, 안내, 재개는 모임 종료 시각을 늘리지 않는다. 수업 자료와 세션 원문은 그대로 둔다.

자세한 계약은 [수업 터미널](../README.md#선택한-자리의-수업-터미널-함께-실행), [0단계 일시정지](../README.md#수업-비상-제어-0단계--명령-전달-일시정지), [1단계 시험·미리보기](../README.md#수업-비상-제어-1단계--시험용-실습실과-전달-미리보기), [2단계 상태판](../README.md#수업-비상-제어-2단계--참여자-상태판), [3단계 중단 요청](../README.md#수업-비상-제어-3단계--수업-터미널-프로그램-중단-요청), [4단계 파일](../README.md#수업-비상-제어-4단계--파일-체크포인트와-zip-직접-확인), [5단계 복구·교체](../README.md#수업-비상-제어-5단계--자리-연결-복구와-실습실-교체)에 있다.

## 네 가지 동작을 구분한다

| 동작 | 하는 일 | 하지 않는 일 |
|---|---|---|
| 전달 일시정지 | 새 수업 터미널 준비와 명령 전달을 막는다. 다시 보내려면 현재 상태 번호로 명시적 재개한다. | 이미 전달된 명령, 개인 터미널, 실행 중인 프로그램을 거두지 않는다. 재개가 남은 자리를 자동 실행하지 않는다. |
| 범위 Ctrl+C | 일시정지 뒤, 고른 자리의 `gw-lesson` 첫 창·첫 pane에만 중단 요청을 보낸다. | 개인 터미널, 다른 pane, 샌드박스 전체를 멈추지 않는다. 전달됨이 종료나 저장을 뜻하지 않는다. |
| 전송 세션 중지 | 그 수업 터미널 제어 세션의 이후 전달을 닫는다. | 일시정지를 대신하지 않는다. 이미 실행 중인 프로그램을 끝내지 않는다. |
| 모임 종료 | 같은 모임의 원래 실습실과 교체로 만든 실습실을 모두 정리한다. | 파일 보존이 아니다. 외부에서 ZIP을 열어 확인하기 전에는 쓰지 않는다. |

전체 중지, 전체 삭제, 참여자 원본 샌드박스를 외부 보관 확인 전에 지우기, 결과를 모르는 요청의 자동 재시도, 예산 초기화나 새 허용량, 완전한 통제나 자동 복원이라고 말하는 일은 하지 않는다.

## 증상별 절차

| 증상 | 첫 조치 | 확인 | 복구·에스컬레이션 |
|---|---|---|---|
| 잘못된 명령을 여러 자리에 보냄 | 전달 일시정지. 대상 자리만 다시 고른다. | 상태판의 마지막 전달은 입력 기록이다. 이미 나간 입력은 회수되지 않는다. | 수업 터미널 프로그램만 범위 Ctrl+C. 다음 명령은 시험 실습실과 미리보기로 원문·자리를 다시 확인한 뒤 명시적 재개. |
| 수업 터미널 프로그램이 계속 실행됨 | 일시정지 후 그 자리만 실행 프로그램을 확인한다. | 대상이 `gw-lesson` 첫 pane인지, 개인 터미널이 아닌지 본다. | 확인이 맞으면 그 자리만 Ctrl+C. 개인 터미널은 참여자가 직접 본다. 샌드박스를 끄거나 지우지 않는다. |
| 끊김, 느린 와이파이, 편집기가 늦게 열림 | 일시정지해 새 전달을 멈춘다. 바로 교체하지 않는다. | 상태판이 연결 끊김인지, 편집기만 느린지 구분한다. 약 30초 캐시가 옛 연결을 보여줄 수 있다. | 한 자리만 기존 연결 복구로 편집기 상태를 본다. 자료 재설치나 파일 덮어쓰기는 하지 않는다. 복구 성공이 파일 복구는 아니다. |
| 공급자 전체 장애 또는 할당량 | 일시정지. 같은 요청을 반복하지 않는다. | 상태판·복구 결과가 불명인지, 예산 세션이 그대로인지 본다. | 새 예산을 발급하거나 사용량을 초기화하지 않는다. 공급자가 돌아올 때까지 기다리고, 불명 생성은 아래 불명 요청 절차로 올린다. |
| 파일이 없거나 내용이 이상함 | 일시정지. 참여자에게 편집기 저장을 안내하고 자리 하나의 체크포인트를 만든다. | ZIP은 work를 덮어쓰지 않는 새 폴더다. 바이트 전송 완료와 사람이 ZIP을 열어 확인한 기록은 별개다. | 참여자가 자기 자리의 그 보관본만 받아 연 뒤 확인을 남긴다. 확인 없는 교체는 손실 동의란을 따로 고르기 전에는 하지 않는다. 자동 복원이나 원본 덮어쓰기는 없다. |
| 요청 결과를 모름, 또는 같은 자리가 겹침 | 같은 요청 ID만 다시 읽는다. 새 ID로 재실행하지 않는다. | 응답이 없어도 생성은 이미 받아들여졌을 수 있다. 자리 잠금이 있으면 다른 복구는 거절된다. | 교체 응답의 샌드박스 ID를 못 받으면 Daytona에서 부모 실습실(`gw-lab`)과 요청 ID의 `gw-recovery` 라벨을 직접 본다. 연결 복구라면 원래 편집기와 기동 요청 상태를 본다. **복구 대상·파일 상태 확인**으로 현재 자리를 다시 읽고 점검 확인란으로 잠금을 푼다. 해제는 취소나 삭제가 아니다. ID를 아는 미채택 새 자원은 별도 정리 대기에서 다루며, 원본을 추측해서 지우지 않는다. |
| 한 자리를 수리해도 복구되지 않음 | 그 자리만 남기고 일시정지를 유지한다. | 편집기 확인은 자료·실행 프로그램 복구가 아니다. 예산 키·사용량·종료 시각은 그대로여야 한다. | 파일 확인 또는 명시적 손실 동의 뒤에만 그 자리 교체. 새 실습실과 접속 정보를 적용하고 예전 초대는 버린다. 원본 샌드박스는 모임 종료까지 둔다. 외부 ZIP 확인 전에 복구 수단으로 원본을 지우지 않는다. 참여자는 새 링크로 개별 입장한다. |
| 관리 인증 만료, 다른 탭의 옛 재개 | 화면을 새로고침하고 다시 인증한다. 일시정지는 유지된다. | 상태 번호가 다르면 재개·전달은 거절된다. 확인되지 않은 화면에서는 보내지 않는다. | 현재 번호로만 재개한다. 다른 탭의 옛 재개·전달 확인 화면은 다시 만들고, 이미 보낸 동작은 같은 요청 ID로 조회한다. 재인증이 전달을 풀거나 명령을 보내지 않는다. |
| 모임 시간이 끝나 가거나 종료해야 함 | 종료 시각을 늘리지 않는다. 남은 자리에 저장과 ZIP 열기 확인을 요청한다. | 미확인 자리 수를 종료 확인에서 본다. 내부 체크포인트는 종료·만료와 함께 사라진다. | 외부 보관이 확인된 뒤에만 모임을 끝낸다. 종료는 원래 실습실과 새 실습실을 모두 지운다. 안내나 확인 표시로 만료가 연장되지 않는다. |

## 모임 5분 전 리허설

본 모임, 참여자 자리, 실제 자료에는 들어가지 않는다. 전용 더미 모임과 더미 파일만 쓴다.

1. 더미 모임을 열고 명령 전달을 일시정지한 뒤 상태 번호를 읽는다.
2. 더미 자리 하나만 골라 체크포인트를 만든다. work를 덮어쓰지 않고 새 폴더에 ZIP이 생기는지 본다.
3. 그 자리 참여자 경로로 그 체크포인트만 받는다. 전송이 끝나도 확인 전인 것을 보고, ZIP을 연 뒤에만 확인을 남긴다.
4. 파일 확인이 있는 그 더미 자리만 교체해 본다. 같은 요청을 다시 실행하지 않는다. 원본 샌드박스는 아직 지우지 않는다.
5. 옛 상태 번호의 재개는 거절되고, 현재 번호의 재개만 되며, 재개가 수업 터미널에 명령을 보내지 않는지 본다.
6. 더미 모임을 끝낼 때만 원래 실습실과 새 실습실이 함께 정리되는지 본다. 본 모임의 자료와 세션은 열지 않고 그대로 둔다.

## 사건 뒤 수업으로 돌아가기

1. 화면을 새로고침해 현재 상태 번호와 일시정지 여부를 다시 읽는다.
2. 자리를 바꾼 참여자는 새 초대 링크로 개별 입장한다. 파일은 자동 복사되지 않으므로 보관한 ZIP을 새 실습실에서 따로 확인한다.
3. 새 수업 터미널이 필요한 교체·세션 중지 후에는 현재 번호로 명시적 재개하고, 대상을 다시 골라 수업 터미널을 새로 준비한다. 재개나 준비가 이전 명령을 자동 전송하지 않는다.
4. 정상인 기존 세션을 유지한 경우에는 대상·소유권을 다시 확인한다. 새 명령의 시험 실행과 미리보기는 현재 원문·자리로 다시 한다.
5. 아직 일시정지라면 현재 번호로 명시적으로 재개한다. 상태가 바뀌어 확인 화면이 무효가 되면 미리보기를 다시 만든다.
6. 마지막 전달 확인 버튼을 별도로 누른다. 확인되지 않은 자리에는 보내지 않는다.
7. 수업 자료와 모임 종료 시각은 바꾸지 않는다.

## 이 절차가 증명하는 범위

[자동 모의훈련](../tools/test-classroom-emergency.mjs)은 `node tools/test-classroom-emergency.mjs --full`로 실행한다. [통합 훈련](../test/lab-emergency-drill.mjs)은 실제 State와 합성 저장소·차단된 공급자 응답으로 파일 확인부터 교체·재개·종료와 불명 생성·잠금 해제를 묶는다. [workerd·SQLite 훈련](../test/lab-seat-recovery-workerd.mjs)은 실제 로컬 저장소와 재시작 후 사용량·토큰·요청 기록 보존을 확인한다. 실제 Daytona 생성·과금·참여자 파일·설치된 PWA 조작을 증명하지 않는다. README의 네이티브 ZIP·tmux 검사도 별도 임시 환경이며 본 모임에 연결하지 않는다. 모임 전 더미 리허설은 사람이 직접 해야 한다.
