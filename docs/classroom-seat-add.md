# 작은 도구 창과 진행 중 좌석 추가

상단의 **설정**은 작은 도구 버튼이며 **새 모임**은 그 안에서 연다. 누르면 현재 수업 위에 창을 열고, 닫기나 Escape로 돌아온다. 모임이 없어도 자동으로 창을 띄우지 않는다. 새 모임 양식의 초안과 진행 중 화면 공유는 창을 오가는 동안 유지한다.

설정은 최대 520px 폭으로 인증 상태·로그아웃·기기 알림·앱 설치를 모은다. 긴 알림 설명과 설치 안내는 펼쳐서 읽는다. 수업 단계와 자료를 편집하는 기존 **수업 준비** 메뉴는 현재 모임의 수업 구성용으로 유지한다.

## 수업 중 한 자리 열기

1. 상단에서 진행 중인 모임을 고르고 **좌석 추가**를 누른다.
2. 현재 자리 수, 새 자리의 CPU·메모리·디스크·AI 한도와 모임 종료 시각을 확인한다.
3. **1자리 추가**에서 추가 자원·비용 안내를 확인한다. 현재 모임에 한 자리만 새로 만든다.
4. 결과가 준비되면 **새 좌석 초대**를 눌러 새 자리 전용 QR·링크를 전달한다.
5. 더 필요하면 창을 다시 열고 **다른 좌석 추가**를 누른다.

기존 참여자의 파일·자리 번호·접속 정보와 모임 종료 시각은 바꾸지 않는다. 새 좌석은 기존 모임의 사양·모델·자료·클립보드 정책·API 공유 설정을 따르고, AI 한도는 새 자리에도 별도로 적용한다. 모임당 최대 20자리이며 실제 Daytona 조직 자원 한도에 따라 준비가 실패할 수 있다. 종료·시연 전용·체험 연결 모임에는 추가하지 않는다.

관리 세션이 필요하다. 기존 8시간 관리 권한을 사용하며 별도 요청함의 보안 키 승인 절차는 바꾸지 않는다.

## 응답이 늦거나 끊겼을 때

시간 초과는 생성 실패를 뜻하지 않는다. **같은 요청 결과 확인**으로 조회하고 새 요청을 반복하지 않는다. 브라우저 새로고침 뒤에도 같은 탭에서 좌석 추가를 열면 남은 요청을 조회한다. 자동으로 다시 생성하지 않는다. 준비 대기나 미시작이 확인된 경우에만 **같은 요청으로 계속 준비**를 제공한다.

탭의 sessionStorage에는 모임 ID·생성 요청 ID·조건 지문만 보관한다. 관리 토큰·초대 코드·파일·공급자 키는 넣지 않는다. 새로고침 복구는 같은 탭 기준이며 탭 종료 후의 영구 복구 기록을 약속하지 않는다. 실습실 준비를 완료하지 못한 자리 기록은 완료된 초대로 표시하지 않으며, 모임 도구의 기존 복구 상태를 확인한다.

서버는 기존 생성 작업 기록과 자원 정리 절차를 재사용한다. 같은 요청을 동시에 보내거나 재시작 뒤 재조회해도 추가 생성하지 않는다. 좌석 할당은 트랜잭션으로 20자리 한도를 검사한다. 확인한 모임 조건이 바뀌면 자원을 만들기 전에 거절한다.
