This closing is already included in both three-minute scripts.

HOST PROCEDURE
1. Open the host approval URL and sign in as the configured owner through
   Cloudflare Access. Have the already registered physical security key ready.
2. Review the pending request. For this demo, choose personal practice and
   check its duration, AI budget and resource limits.
3. Press "보안 키로 승인하고 열기". Select the security key, enter the key's
   PIN if requested, and touch the key. The key must be enrolled for shinick.dev.
4. Approval starts resource creation. If the page stays in the approved /
   creating state, press "같은 요청으로 생성 결과 확인" on the SAME request.
   Creation does not retry automatically. Do not submit a second request.
5. The attendee keeps the original request page open in the same browser.
   Its status checks run every 10 seconds while visible. Once ready, the
   attendee sees their personal entry link. The host inbox does not expose it.
6. Continue the pitch while the sandbox is being prepared. Provisioning
   speed and capacity are not guaranteed.
