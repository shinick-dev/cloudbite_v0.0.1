Never display the owner's private operator QR or credential.

PARTICIPANT
1. Scan the public QR. Enter your name and what you want to try in Cloudbite.
2. Keep the request page open in the same browser. A server-managed HttpOnly
   cookie identifies your application; the request ID alone grants no access.
3. When the host approves, use Continue to Cloudbite in that browser.
4. Enter a shared project, choose up to five expert roles, then press Run experts.
   Approval alone never starts compute. The approved trial permits up to ten
   projects in one hour; pending requests expire after 30 minutes.
5. The project and its experts use independent workspaces. Other participants
   cannot recover your project by reusing the same client request ID.

OWNER
1. Open the Cloudbite owner inbox using the private owner access file's inbox
   button, or enter a valid temporary Cloudbite operator / Cloudbite admin token.
2. Review the applicant's name and purpose. Press Approve or Deny.
3. Approval is recorded by Cloudbite itself. The temporary owner credential is
   sufficient; no physical-key tap is required for this Cloudbite flow.
4. Use Revoke to stop future creation by an approved visitor. Already issued
   project capabilities retain their existing 24-hour read/cancel policy.

BOUNDS
Up to ten projects per approved one-hour visitor session, up to five experts each;
existing global live limits still apply (two active projects, three expert
workers per project at once).
Resource contention and provider errors are shown explicitly. No immediate
successful Daytona + Nosana execution is promised by admission approval.
