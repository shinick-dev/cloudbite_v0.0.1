# 내 파일을 실습실에 올려 작업하기

자기 컴퓨터의 파일을 실습실로 가져와 OpenCode에 읽기·정리·수정을 요청할 수 있습니다. 실습실이 열려 있는 동안 이용합니다.

## 파일 올리기

1. 화면 오른쪽 아래 **파일 올리기 안내**를 누르면 실습실 안에서도 이 방법을 다시 볼 수 있습니다. 이 버튼은 안내를 여는 버튼입니다.
2. 왼쪽 **탐색기(파일 목록)**에서 **work 폴더**를 오른쪽 클릭하고 **Upload… (업로드)**를 선택합니다. 파일 하나의 메뉴가 아닌 폴더 메뉴입니다.
3. 자기 컴퓨터의 파일을 선택합니다. 목록에 파일 이름이 나타나는지 확인하고 파일을 열어 내용을 확인합니다. 같은 이름의 파일이 있으면 덮어쓰기 전에 확인하세요.

Windows 탐색기·Finder에서 파일을 끌어 **실습실 왼쪽 파일 목록**에 놓아도 됩니다. OpenCode 대화창에 `C:\...` 같은 내 PC 경로만 붙여넣으면 실습실로 파일이 올라가는 것은 아닙니다.

## AI에게 요청하기

개인 입력용 터미널에서 OpenCode를 열고, 올린 파일의 실제 이름으로 바꿔 요청합니다.

> 내메모.txt를 읽고 핵심 내용을 정리해줘. 원본은 유지하고 결과는 정리.txt로 저장해줘.

파일을 찾지 못하면 추측해서 원본을 만들게 하지 마세요. 파일 목록에서 업로드된 위치와 이름을 확인한 뒤, 그 경로를 알려주세요. “저장했다”는 답변을 받은 뒤에는 실제 결과 파일을 열어 원본과 대조합니다.

## 2주차 복습 ZIP으로 연습하기

ZIP을 내 PC에서 먼저 압축 해제하고, `원본` 폴더 안의 `01_요청메모.txt`와 `02_진행메모.txt` 두 파일만 `work`에 올립니다. 이미 같은 파일이 있으면 다시 올릴 필요 없이 내용부터 확인합니다. 그다음 복습 PDF 4쪽의 첫 요청으로 이어갑니다. 실습실 링크가 종료됐다면 업로드는 할 수 없으므로 PDF 8쪽의 AI 대화창·메모장 경로를 사용합니다.

## 파일 형식과 보관

- TXT·CSV 같은 텍스트 파일부터 시작하세요. Word·Excel·PDF·사진은 업로드 성공과 AI의 내용 읽기 성공을 따로 확인해야 합니다. 변환·읽기 도구나 이미지 지원이 필요할 수 있습니다.
- 실습실 화면은 모임지기에게 공유됩니다. AI에게 읽도록 요청한 내용은 모델 제공자에게 전달되므로 회사 기밀·개인정보가 없는 연습용 사본을 사용하세요.
- 작업을 마치면 저장 → **내 작업 받기** → ZIP 압축 해제 → 내 컴퓨터에서 결과 파일 직접 열기 순서로 확인합니다. 실습실은 임시 공간이며 내부 체크포인트만으로는 모임 종료 뒤 보관이 보장되지 않습니다.

## 모임지기 참고

업로드는 code-server의 기본 기능을 사용합니다. 안내 버튼은 별도 전송 API나 업로드 완료 표시를 만들지 않습니다. 안내를 열었다는 사실은 업로드·읽기·학습 완료를 의미하지 않습니다. 새 안내 버튼은 실습실 페이지 새로고침으로 반영됩니다. 이 저장소의 `lab/files/README.md` 변경은 새 스냅샷을 만들 때 들어가므로 기존 실습실 README에는 자동 반영되지 않습니다.
