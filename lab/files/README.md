# AI 실습실

여기는 이번 수업 동안만 쓰는 나만의 리눅스 컴퓨터입니다. 수업이 끝나면 이 안의 파일과 기록이 모두 지워집니다.

## 터미널 열기

왼쪽 위 메뉴 ☰ → **Terminal → New Terminal** (단축키 `` Ctrl + ` ``)

## AI 코딩 도구

```bash
claude      # Claude Code
opencode    # OpenCode
lab-status  # 남은 사용 한도·수업 시간·실제 자원
lab-resources --json # 읽기 전용 자원 진단 (AI 호출·과금 없음)
lab-doctor  # 안 될 때 자가 진단 (결과를 강사에게 보여 주세요)
```

- 둘 다 로그인 없이 바로 됩니다.
- 두뇌는 OpenRouter 의 공개 모델입니다 (`echo $LAB_MODEL` 로 확인). Claude Code 라는 "도구"에 다른 "모델"을 끼운 것이라, Claude 모델과는 답이 다를 수 있습니다.
- 1인당 사용 금액 한도가 걸려 있습니다. 한도를 넘으면 오류가 납니다. Claude Code 아래쪽 상태 줄에도 남은 한도·시간이 보입니다.

## 이 수업에서 쓸 수 있는 API 키

강사가 이 수업에 검색·음성 같은 API 키를 나눠 줬다면 환경변수에 이미 들어 있습니다 (`echo $LAB_SHARED` 로 목록 확인).

- 들어 있는 건 **가짜 토큰**입니다. 게이트웨이(`…_BASE_URL` 주소)를 거쳐야만 진짜 키로 바뀌어 나가므로, 공식 SDK 를 쓸 때는 base URL 환경변수도 같이 써 주세요.
- 자리마다 호출 수 상한이 있고, 강사가 수업 중에 끄거나 바꿀 수 있습니다. 남은 횟수는 `lab-status`, 되는지 확인은 `lab-doctor`.
- 상한을 넘으면 429, 강사가 껐으면 403 오류가 납니다 (한국어 안내가 같이 옵니다).

## 복사·붙여넣기

- 편집기·터미널: 드래그로 고르면 바로 복사됩니다. `Ctrl + C` / `Ctrl + V`, 터미널에서는 오른쪽 클릭도 복사·붙여넣기.
- **OpenCode 화면**은 마우스를 직접 쓰므로 **Shift 를 누른 채 드래그**해서 고르세요.
- 처음 붙여넣을 때 브라우저가 클립보드 권한을 물으면 **허용**.

## 도움 받기

- 화면 오른쪽 아래 **✋ 손 들기** → 강사 화면에 표시됩니다.
- 강사가 같이 봐야 할 때: 터미널 오른쪽 위 **+ 옆 ⌄ → "공유 터미널 (강사와 같이 보기)"** 에서 작업하세요. 강사가 같은 터미널에 들어와 보고 입력할 수 있습니다.

## 내 파일 올리기

화면 오른쪽 아래 **파일 올리기 안내**에서 방법을 다시 볼 수 있습니다.

1. 왼쪽 파일 목록의 `work` 폴더를 오른쪽 클릭 → **Upload… (업로드)** → 내 컴퓨터의 파일 선택.
2. 파일 목록에 나타난 파일을 직접 열어 내용이 맞는지 확인합니다. Windows 탐색기·Finder에서 왼쪽 파일 목록으로 끌어다 놓아도 됩니다.
3. OpenCode에 실제 올린 파일 이름과 할 일을 알려주세요. 예: `내메모.txt를 읽고 핵심 내용을 정리해줘. 원본은 유지하고 결과는 정리.txt로 저장해줘.`

처음에는 TXT·CSV 같은 텍스트 파일을 쓰세요. Word·Excel·PDF는 올리는 데 성공해도 읽기 도구나 변환이 필요할 수 있습니다. 회사 기밀·개인정보가 없는 연습용 사본을 쓰고, 같은 이름의 기존 파일을 덮어쓰지 않도록 확인하세요. 실습실은 임시 공간이므로 결과는 아래 방법으로 가져갑니다.

## 파일 가져가기

화면 오른쪽 아래 **⬇ 내 작업 받기** → `work` 폴더가 zip 으로 받아집니다 (node_modules 등 제외).
파일 하나만이면 왼쪽 파일 목록에서 오른쪽 클릭 → **Download**.

## 주의

- 회사 코드·문서, 개인정보는 넣지 마세요. 입력한 내용은 AI 모델 제공자에게 전달됩니다.

## 자원과 동시 작업

`lab-resources`는 현재 cgroup v2와 보이는 조상의 CPU quota·cpuset, 메모리 한도·사용량·여유, 누적 OOM 발생(events)·프로세스 종료(kills), 루트와 work 파일시스템의 사용 가능한 디스크를 읽습니다. 조상 메모리 여유는 형제 작업의 사용량도 반영합니다. CPU throttled는 누적 시간이며 현재 CPU 부하가 아닙니다. `unknown`은 확인 불가, `unlimited`는 보이는 cgroup에 제한이 없다는 뜻이며 호스트 용량을 보장하지 않습니다. cgroup v1은 지원하지 않아 unknown으로 표시합니다. cgroup namespace에서 보이지 않는 조상 제약은 확인할 수 없으므로 실제 전체 여유를 확정하지 못합니다. mount root의 제한 파일이 없을 때도 전역 root라고 단정하지 않고 관련 제약·effective CPU·메모리 여유를 unknown으로 표시합니다.

동시 빌드·에이전트 수는 실제 effective CPU와 메모리 headroom에 맞춰 줄이세요. 이 진단은 설정을 변경하거나 AI 사용량을 소비하지 않습니다. `lab-doctor`의 모델 연결 검사에는 기존처럼 AI 호출이 있습니다. 새 helper와 안내는 새 스냅샷으로 만든 수업에 전달되며 기존 수업에는 자동 반영되지 않습니다.
