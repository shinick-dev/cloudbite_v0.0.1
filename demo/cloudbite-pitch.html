    Guide: how Cloudbite works

    One shared project, five expert roles, each in its own workspace, returning structured opinions with evidence.

    One project, a different question for each expert.

    Personas written with reference to pro-bably role metadata each receive a different work order. Product looks at demand validation, Security at data boundaries, and Finance at unit economics.

    PERSONA.md + PROJECT.md + WORKORDER.md

    Daytona is where the experts actually work.

    Each sandbox receives a persona and the project, then runs Python calculations and file operations. The goal is an experience where calculation tables, risk lists and execution plans remain alongside the chat answer.

    per-expert isolation → tool runs → out/ artifacts

    Work through Nosana inference, return with evidence.

    In the real implementation, models are called through a server-managed inference path. Every model call and run log in this mock-up is an example and connects to nothing external.

    work order → inference / tools → structured opinion

    Show what would change the decision, not just consensus.

    See the distribution of directions alongside self-reported confidence, and follow concerns all the way to their evidence files. The user makes the final choice; the system proposes the next validation step.

    Prove it with 5, scale to 100.

    The current implementation target is a run with up to 5 experts selected from 12 roles. Running 100 experts concurrently, automatic expert selection and real accuracy calibration are future scope. The statistics and judgments on this screen are calculated only from prepared example data.

    What this preview is, and how to move around it.

    What you are looking at

    A transparent scripted simulation of one Cloudbite run. Every opinion, number, file and activity line is prepared example data embedded in this page. Daytona provides the per-expert workspaces and Nosana provides inference in the real product; neither is contacted here.

    Reading the numbers

    • Counts are an unweighted tally of completed opinions by direction.
    • The recommendation text is an authored sample, not a computed output.
    • Self-reported confidence is not accuracy. There is no validated reliability score.
    • Incomplete or failed opinions are excluded from the tally.

    Keyboard

    • Tab moves between controls.
    • ← → Home End switch tabs inside a tab list.
    • Esc exits the full-screen execution stream.

    Replay
