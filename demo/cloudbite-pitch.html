합성된 실행 기록

    프로젝트는 하나, 맡기는 질문은 다르게.

    pro-bably의 역할 메타데이터를 참고해 작성한 페르소나가 각자 다른 작업 지시를 받습니다. 제품은 수요 검증을, 보안은 데이터 경계를, 재무는 단위 경제성을 살펴봅니다.

    PERSONA.md + PROJECT.md + WORKORDER.md

    Daytona는 전문가가 실제로 일하는 장소.

    각 샌드박스에 페르소나와 프로젝트를 넣고, Python 계산과 파일 작업을 수행하게 합니다. 채팅 답변과 함께 계산표·위험 목록·실행 계획이 남는 경험을 목표로 합니다.

    전문가별 격리 → 도구 실행 → out/ 산출물

    Nosana 추론으로 일하고, 근거로 돌아옵니다.

    실제 구현에서는 서버가 관리하는 추론 경로를 통해 모델을 호출합니다. 이 목업의 모델 호출과 실행 로그는 모두 예시이며 외부에 연결하지 않습니다.

    작업 지시 → 추론 / 도구 → 구조화된 의견

    합의보다, 결정이 바뀌는 조건을 드러냅니다.

    찬반 분포와 자기확신을 함께 보고, 우려 의견도 근거 파일까지 따라갑니다. 최종 선택은 사용자가 하고, 시스템은 다음 검증 행동을 제안합니다.

    5명으로 증명하고, 100명으로 확장합니다.

    현재 구현 목표는 12개 역할 중 최대 5명을 선택한 실행입니다. 100명 동시 실행·자동 전문가 선발·실제 정확도 보정은 향후 범위입니다. 이 화면의 통계와 판단은 준비된 예시 데이터로만 계산됩니다.
