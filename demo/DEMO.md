> Daytona HackSprint Seoul · 2026-10-18 · 17:00 라이브 데모

## 0:00–0:15 문제
"AI에게 일을 맡기면, 답은 받지만 **실행 증거**가 없습니다.
Cloudbite는 하나의 프로젝트를 **여러 전문가 페르소나가 각자의 독립 Daytona 샌드박스에서**
수행하고, 결과와 근거를 한 화면에서 비교하는 작업 공간입니다."

## 0:15–1:15 라이브: 실제 샌드박스 3개가 동시에 뜬다
```powershell
cd cloudbite_v0.0.1
.\demo\run-council.ps1
```
- 화면에 찍히는 것: 역할별 샌드박스 이름, **생성 시간(≈0.8초)**, 실행 시간(≈1.7초), 원격 host ID
- 강조 포인트: "지금 이 순간 원격에 3개의 격리된 컴퓨터가 생겼고, 각자 코드를 실행했습니다."
- `demo/evidence.json`에 실행 증거가 남습니다 (샌드박스 ID·호스트·파이썬 버전 포함)
