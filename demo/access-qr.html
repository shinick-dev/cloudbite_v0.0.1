From request to workspace

  1. Tell us what you want to try.Enter your name and a short task. The request form is currently in Korean: choose 혼자 복습할 개인 실습실 (personal practice workspace).
  2. The host approves with a security key.Your request waits in the host's inbox. The host chooses the session limits and confirms this request with the key.
  3. Open your personal entry link.Keep the request page open. Once provisioning is ready, it shows the link to your assigned sandbox.

One participant, one workspace.

This uses the existing sandbox request service. Approval is required, and provisioning can take a little time. The QR itself grants no access.

Use the same browser to check your request. The confirmation information stays in that browser. This participant flow is separate from the simulated expert workspaces in the pitch preview.
